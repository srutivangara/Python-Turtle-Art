# Python Turtle Graphics

A simple project built using Python's built-in `turtle` module for drawing graphics and creating animations.

## 📋 Description

This repository contains Python scripts that use the `turtle` graphics library to draw shapes, patterns, and simple animations on screen.

## 🛠️ Requirements

- Python 3.x
- `turtle` module (comes pre-installed with Python's standard library)

No additional installation is required for the `turtle` module itself.

## 🎨 Features

- Draw basic shapes (squares, circles, polygons, stars)
- Create colorful patterns and spirals
- Simple animations using turtle movement
